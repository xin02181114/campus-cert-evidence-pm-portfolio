## 💡 项目概述
本项目以“校园竞赛获奖证书”为业务场景，基于 FISCO BCOS 2.11.0 联盟链，实现证书哈希的链上存证与防伪验证。本人以**项目经理**视角主导全流程，从需求分析、范围界定、进度规划到风险控制、技术落地与测试验收，产出了完整的全生命周期管理文档与可验证的技术成果。

## 🛠️ 技术实现与核心数据
*   **底层网络**：Ubuntu 20.04 本地部署 FISCO BCOS 4 节点联盟链。
*   **智能合约**：使用 Solidity 编写存证合约。
*   **核心测试结果**：存证交易回执 `0x0`；存在性验证返回 `true`；防伪验证返回 `false`。
