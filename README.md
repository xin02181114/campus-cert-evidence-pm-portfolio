## 💡 项目概述
本项目以“校园竞赛获奖证书”为业务场景，基于 FISCO BCOS 2.11.0 联盟链。项目经历了两次重大迭代：从 V1.0 的“基础存证闭环”，进阶到 V2.0 的“RBAC 权限安全管控”，完整展示了从技术落地到业务安全升级的项目管理全过程。

## 🛠️ 技术实现与核心突破
*   **底层网络**：Ubuntu 20.04 本地部署 FISCO BCOS 4 节点联盟链。
*   **权限架构（V2）**：通过 Solidity 的 `modifier onlyAuthorized`，硬性拦截未授权地址的恶意发证。
*   **技术突破**：针对官方控制台对 `bytes32` 类型解析的 ABI 编码 Bug，主动重构合约，改用 `string` 参数配合 `keccak256` 转换，成功规避工具缺陷完成测试。

## 🎯 项目管理复盘
*   **敏捷迭代思维**：不满足于初始可用状态，主动识别“无权限控制”的业务痛点，完成了 V2.0 版本的安全演进。
*   **以结果为导向**：在遭遇工具链报错时，没有死磕底层代码，而是采用业务层变通策略，确保测试如期验收。
