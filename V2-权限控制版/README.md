# V2.0 权限控制版（RBAC）—— 交付说明

本目录为校园数字证书存证系统的 **V2.0 最终交付版**。

## 💡 为什么进行 V2 迭代？
在 V1.0 基础版跑通后，项目组进行安全审计时发现了一个致命业务漏洞：**“任何人皆可调用接口发证”**。为了模拟真实的发证场景，防止恶意节点伪造证书，V2.0 版本进行了架构升级。

## 🛡️ 核心升级：引入 RBAC 模型
- **超级管理员（Owner）**：教务处。拥有部署合约、授权/撤销机构发证权限的绝对控制权。
- **授权发证方（Issuer）**：学院或社团。必须经教务处授权后，方可调用 `createEvidence` 上链存证。
- **公开验证方（Verifier）**：企业 HR 或公众。无需权限，随时可调用 `verifyEvidence` 查真伪。

## 🔥 技术与测试亮点
1. **安全防御验证**：成功通过代码测试，证明了未授权的“黑客”账户强行调用发证接口时，会被 `onlyAuthorized` 修饰器拦截，交易回滚并报错 `Not authorized to issue`。
2. **突破工具链 Bug**：在测试中遭遇官方控制台 ABI 编码缺陷。通过将合约参数由 `bytes32` 重构为 `string`，并在内部通过 `keccak256` 转换，成功绕开官方工具缺陷，保证项目按期验收。
